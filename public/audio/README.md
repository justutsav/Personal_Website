# Timeline music

Files (numbered per track; edit the `TRACKS` array in `components/MusicDisk.tsx`):

    1.mp3  / 1.jpg   track 1 audio + cover
    2.webm / 2.webp  track 2 audio + cover
    3.mp3  / 3.webp  track 3 audio + cover
    4.mp3  / 4.webp  track 4 audio + cover
    5.mp3  / 5.jpg   (add more the same way)

Plays only across the Selected Work + Timeline sections; auto-starts once the
Selected Work section opens, fades in/out, and `‹ ›` switch tracks.
